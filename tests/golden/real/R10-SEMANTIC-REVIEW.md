# R10 真实病例语义确认清单

状态：待产品主看图确认。下列问题不影响独立像素测量的可复现性；确认后如需改变语义目标，应更新对应 ground truth 的说明或新增人工审校验收，而不是用管线输出反推答案。

## rw-02

- [ ] 确认从左到右确为六个时间序列帧，顺序不可互换。
- [ ] 确认六帧内容高度/垂直位置差异属于允许的动作变化，不标尺寸离群。
- [ ] 确认第 4、6 帧中的小型独立 alpha 碎片属于对应帧；按 `componentMinAreaPx=4`，两帧应标 `multipleComponents=true`。
- 测量证据：六段前景间距 CV=`0.459754`；透明槽网格置信度 `0.957692`，当前标注为 `grid / 6`。

## RW-03

- [ ] 确认画面语义上是两个独立角色，而不是一个双人组合帧。
- [ ] 确认重度桥接区域仍应由用户在降级后的中线附近手动拆分；协调会话估计桥接宽度约 75px。
- 测量证据：全图经膨胀/近邻处理后只有一个有效候选，当前按 r4 公式标注为 `manual-grid 1×2 / INSUFFICIENT_COMPONENTS`。

## RW-04

- [ ] 确认帽子、法杖与效果断件都属于同一个角色/同一帧，而非两个姿态。
- [ ] 确认产品预期是提示人工合并/重画框；r4 自动降级给出的 `1×2` 只是建议网格，不代表两个语义帧。
- 测量证据：阈值及面积过滤后全图有六个原始组件，膨胀后归为一个有效候选；断距参考为短边的约 `0.9%–2.7%`。

## RW-05

- [ ] 确认从左到右确为八个语义动作帧。
- [ ] 指认预期的“相似帧对”；确认它们只是相似，不是应折叠的逐像素重复帧。M1 的 `duplicateOf` 仍应为 `null`。
- [ ] 确认当前病例重点是验证透明内容桥接导致的诚实降级，而不是要求 M1 自动恢复八帧。
- 测量证据：有效内容最终并为一个候选，网格置信度仅 `0.775`，当前按 r4 公式标注为 `manual-grid 1×2 / INSUFFICIENT_COMPONENTS`。

## RW-06

- [ ] 确认第 8 帧仍是同一动画序列中的异常帧，应保留并标 `outlier=true`，而不是独立角色或封面图。
- 测量证据：前七帧宽 `206–233px`、高 `300–306px`；第八帧 `375×541px`，相对中位宽高均严格超过 `0.4` 阈值，当前标注为 `grid / 8` 且仅第八帧离群。

## RW-07

- [ ] 确认四团软 alpha 辉光分别属于对应角色帧，bbox 应包含所有 `alpha > 8` 的辉光像素。
- [ ] 确认不存在应从 bbox 排除的装饰性跨帧光效。
- 测量证据：图中半透明像素 `902088`、完全不透明像素仅 `1`；四个网格 cell 各为一个有效原始组件，当前标注为 `grid / 4`。
