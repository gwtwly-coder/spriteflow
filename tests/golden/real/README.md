# 真实素材区

这里的文件用于人工抽检与后续端到端退出验收，不计入合成黄金集的 20/20 分母，也不允许
让网络下载进入 `pnpm golden`。逐文件来源、授权、哈希、尺寸和 alpha 统计见
`sources.json`。

当前两张透明图可用于 M1 上传/检测人工冒烟；`opengameart-man-v14.png` 完全不透明，M1
必须在预检阶段拒绝，只用于验证范围边界和 M2 去底预研。

`generated/`（由 `tools/gen-real.mjs` 创建）中的 CogView 文件属于 AI 生成抽检素材。API
返回具有随机性和临时下载 URL，因此脚本会保存每次请求的固定 prompt、模型、响应时间、
内容类型与 SHA-256，但不会把它纳入字节级可复现门禁。
