B-16 变体 · 低置信度降级（fallback.* + manual.*）
横幅持续显示（非弹窗）；侧栏切换为手动网格并预填建议行列；画布为建议网格帧（全部待确认）。「重试自动检测」可返回自动流程；关闭横幅可折叠为细条。
C-39 变体 · 检测参数重算中（settings.pending + detect.recalculating）
滑杆停手 300ms 后进入此态：帧框降至 40%、几何编辑与导出禁用（真实 disabled，键盘同步不可触发；选择/平移/缩放仍可用）、侧栏出现「松开后重新检测」。preview 结果先上屏，final 完成后角标落色、横幅消失、编辑恢复；替换本身是一个可撤销事务。
C-43 变体 · 筛选空状态（review.filter.none，示例：选「全部待复核」后 flags 被编辑重算清零）
筛选只影响显示：不匹配芯片隐藏、画布帧框降至 15%；清除入口为「全部帧」。播放与导出始终按完整时间轴。
C-68 + C-71 变体 · 显式手动网格（非降级）+ 行列超限错误（契约 r3：confidence=1、degraded=null）
无降级横幅、无 DETECTION_DEGRADED 呈现；侧栏为手动网格，状态栏「手动」。示例 12×50=600 超过 500 帧上限（C-71）：越界 input 红框 + aria-invalid="true" + aria-describedby 指向 role="alert" 错误行，错误文案使用正式词条 manual.grid_too_large（copy-m1.md 已录入，{count} 以 600 替换）；「应用网格」真实 disabled。M1 显式手动固定传 keepEmptyCells=true、region=null。
C-70 变体 · 手动空结果（frames=[]，检测成功而非错误）
无降级横幅；时间轴空态（manual.no_frames + preview.empty）；「导出预览」组隐藏；确认审校/导出/播放控件为真实 disabled（键盘不可触发），导出按钮以 aria-describedby 挂 export.disabled_no_frames 可访问描述，后续 pack/export 按 NO_FRAMES 阻断。M1 固定 keepEmptyCells=true 通常不会出现该结果，此为防御性承接（契约 r3 §13.2）。
C-69 变体 · 自动降级后应用网格成功（清除横幅，不继承第一次降级）
与 B-16 对照：降级横幅与 DETECTION_DEGRADED 呈现已清除（契约 r3 §13.3 断言矩阵末行）；帧为第二次 manual-grid 结果（原子替换，可撤销），侧栏保持手动网格。EMPTY_INPUT 后应用网格同样走此路径。
