## 2. 机制有效性（有真实战果的）

- **文件所有权表**：全程零合并冲突（唯一事故被即时软重置+披露）。
- **异族验收**：抓出 Ctrl+D 浏览器冲突、PRD/契约三处不一致、可访问性缺失、验收官甚至拉库源码复验 API 映射、复现建议网格帧数冲突。
- **实现者停工条款**：三次契约缺口全部"停下写申请"而非硬写——最高价值条款。
- **机械门禁**：许可审计拦截真实注入演练；CI 并行运行暴露顺序验证的盲区（job 隔离缺陷）。
- **真实素材入库闭环**：产品主踩坑图 → 测量脚本验收 → ground truth → M2 锚点，疫苗生产线转起来了。

## 3. 历史事故与保留的教训（按当前任务适用）

1. **视觉验证缺口**（最重）：8 轮验收无人发现缩略图从未渲染——协调者自己的截图里它就摆着。→ 规则：UI 相关 PASS 必须附运行截图/录屏，DOM/文字断言不单独采信（验收官 Q4 规程，已实战）。
2. **测试断言停在 UI 状态**：删除功能测试只断言到对话框弹出，从未断言"帧真的少了"。Toast 谎报成功、三处 UI 数据源分裂。→ 规则：交互测试必须断言端到端效果（数据变化），不得止步于界面状态。
3. **黄金集多样性缺口**：20 例全 ≤1024px，鬼影 bug（素材图被误用作平铺底纹）结构上不可复现，产品主第一张 >1024px 的图就踩中。→ 规则：黄金集必须覆盖尺寸/编码边界（大图、调色板 PNG、极端宽高比）。
4. **语义一致性**：软删除（included:false）与合并/拆分的硬删除并存于同一 store，行为分裂潜伏整个 M1。→ 规则：同类操作的语义必须在实现评审时对齐。
5. **顺序验证掩盖并行缺陷**：本地顺序跑五门全绿，CI 并行首跑即红（pipeline dist 未构建）。→ 规则：CI 问题必须按 job 隔离复现（每门前清 dist 的全新克隆）。
6. **单供应商额度风险**：Codex 额度耗尽致 R5 停摆一周。→ 保留教训：按当前能力、通道与额度安排替代执行者，交接原始目标和最小必要材料，不固定平台映射。
7. **协调者也会看漏**：RW-06 截图里空缩略图清晰可见而协调者汇报"通过"。→ 保留教训：技术验收必须实际查看关键渲染并独立核对；用户反馈按影响及时处理，不让用户承担发现明显技术缺陷的职责。
