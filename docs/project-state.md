## 保留的产品决定

- 像素不变量：可见 RGB 与源逐字节相等；蒙版内 alpha 保持源值；蒙版外 alpha=0。断言含 PNG 编码后解码复验，失败不生成 ZIP。以 PRD AC-V05 与契约 extractPartPixels 的具体语义为准。
- 性能门槛：确认上传→审校就绪 P50 ≤30s，部位数≤12、最长边≤2048，不含模型冷下载与 LLM 往返；含点击修正及导出的体验耗时单独记录。
- BYOK：key 只进入用户配置的服务商请求，外发前逐次告知与同意；未配 key 不外发图片。非人形/无 key/LLM 失败按 PRD 诚实降级，不擅自增加后端代理。
- BIGMODEL_API_KEY 保留并用于 v3 L1 联调为原 RC 记录的用户决定；本次不读取或更改密钥，不扩大原授权。
- 非人形降级锚点≥1，不占 10 例人形配额；真实单角色素材须单图单角色，不能使用多帧 sprite sheet 或多视图表顶替。
- v3.5 规划主输出为逐帧渲染复用 M1 导出；骨骼格式为进阶选项。这是后续规划，不是当前任务。
- 公共接口或产品范围出现真实冲突时，由 RC 提供具体差异与建议，按授权修订并同步消费者；不单方复制类型或改语义绕过契约。
